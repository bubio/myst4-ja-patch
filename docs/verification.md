# 初版の検証記録

公開用ツールで手元の対応原本から生成し、実画面で確認したローカル版と3アーカイブとも完全一致した。
字幕1,118区間、メニュー等443項目、フォント追加と字幕UIを含む生成結果を照合した。
全分岐の通しプレイ・全台詞の音声照合は未実施。

検証日：2026-11-09。Windows 11、Python 3.10、Pillow 12.3.0、端末内の游ゴシックMediumを使用。

| 生成ファイル | 確認済みローカル版との照合 |
| --- | --- |
| `data/data.m4b` | SHA-256完全一致 |
| `data/english/data.m4b` | SHA-256完全一致 |
| `data/patch.m4b` | SHA-256完全一致 |

これは手元のフォント環境での結果。他のフォントや異なるフォント版を指定した場合、生成物のハッシュが同じになることは保証しない。

単体テストは、入れ子アーカイブの保持、UTF-16の文字数、時刻・空区間、メニュー構造、書式指定子、禁則処理、翻訳対象の完全性を確認する。
適用処理は、未対応データの拒否、適用済み時の無変更、復元の繰り返し、コピー失敗時の復元、部分ファイルの後始末を確認する。
PowerShellの4スクリプトも構文解析を通過した。

## Non-goals

将来のSteam更新版の動作保証、全PC・全フォントの表示保証、実ゲームデータや確認画像の配布。
