# 字幕・メニューの翻訳方針

字幕は話者と場面に合わせた日本語とし、性別だけを理由に一人称や語尾を決めない。
話者を示すファイル名、台詞の呼びかけ、前後の応答、回想と現在の違いを照合する。
映像・音声を全編通して確認した翻訳ではない。話者が混在する場面も文脈から訳しており、曖昧な表現に確定していない設定を足さない。

## 人物別の方針

| 人物 | 手掛かり | 日本語の方針 |
| --- | --- | --- |
| アトラス | `atr`、妻や娘への呼びかけ、装置の説明 | 一人称は「私」。友人には落ち着いた口調、娘には柔らかく話す |
| キャサリン | `cat`、家族との会話 | 穏やかで現実的。母親であることを、不自然に強い女性語に頼らず表す |
| イーシャ | `yee`、本人の「十歳」という台詞、両親への呼びかけ | 「パパ」「ママ」。率直で好奇心が強い子どもの口調。大人の女性のような表現は避ける |
| アクナー | `ach`、ヘヴンの回想、兄としての台詞 | 一人称は「俺」。荒々しさ、ためらい、妹への優しさを場面で区別する |
| シーラス | `sir`、スパイアの独白、実験の説明 | 一人称は「私」。理屈っぽさと自尊心を表す。取り乱した場面も過度に滑稽にしない |
| セレニアの守護者たち | `m01`など、儀式や祖先の説明 | 基本は丁寧な話し方。案内、驚き、警戒の違いを保つ |
| 精霊の導き手 | 夢の世界の説明 | 落ち着いた年長者の語り。「あなた」「旅人」を使い、不要に威圧的にしない |
| 複数人物・回想・人物を装う場面 | `cin`、`a0c`、`y0m`、`b0s`など | ファイル名だけで全行を一人の台詞とみなさず、応答ごとに判断する。外見と内面が異なる場面では変化を意図せず均さない |

アトラス以外の成人の正確な年齢など、台詞から確認していない数値は設定しない。
短い同一台詞を複数人物が共有する場合は、「ありがとう」「本当に？」「駄目！」など自然で中立的な訳を優先する。

既存の完全日本語版の訳文を抽出・流用したものではなく、手元の英語データから作成した日本語訳。
クレジットの人名・社名・作品名は原表記を基本とし、役職・説明文・謝辞を翻訳する。
ヒントの数値、記号、操作順、`%d`などの書式指定子は維持する。

## 表示

字幕の開始・終了時刻、空の区間、参照音声は変更しない。
字幕は原則2行以内とし、設定した文字幅に応じて改行する。
句読点や閉じ括弧を行頭に、開き括弧を行末に置かない。
ヒントの手順・段落は維持し、長い行を折り返す。
日本語の字形は端末内の游ゴシックから作成し、既存の英数字用字形を残して追加する。
